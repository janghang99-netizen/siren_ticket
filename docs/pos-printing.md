# 매장 PC 현장판매 · 번호표 인쇄 설정

현장판매 화면(`/partner/pos`)은 결제가 끝나면 **손님 번호표**를 바로 인쇄합니다.
별도 프로그램 없이, 윈도우에 설치된 영수증 프린터로 크롬이 인쇄합니다.

## 1. 영수증 프린터 준비

1. 프린터 제조사(빅솔론, 세우테크, 엡손 등) 홈페이지에서 **윈도우 드라이버**를 받아 설치합니다.
2. 윈도우 **설정 → 블루투스 및 장치 → 프린터 및 스캐너**에서 그 프린터를 **기본 프린터**로 지정합니다.
3. 프린터 속성에서 용지를 **80mm(또는 58mm) 롤**, 길이는 **자동/연속**으로 둡니다.
   58mm 프린터라면 현장판매 화면의 **인쇄 설정 → 용지 폭**을 58mm 로 바꿉니다.

## 2. 확인 창 없이 바로 인쇄 (권장)

크롬은 보통 인쇄할 때마다 확인 창을 띄웁니다. 매장 PC 에서는 **바로 찍히게** 해 두는 것이 좋습니다.

1. 바탕화면의 크롬 바로가기를 복사해 이름을 `SIREN 현장판매` 로 바꿉니다.
2. 바로가기 **오른쪽 클릭 → 속성 → 대상** 끝에 아래를 붙입니다 (앞에 한 칸 띄우기).

   ```
   --kiosk-printing https://(사이트 주소)/partner/pos
   ```

   예: `"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing https://siren.example.com/partner/pos`

3. 크롬을 **모두 닫은 뒤** 이 바로가기로 엽니다. (이미 열린 크롬이 있으면 옵션이 적용되지 않습니다.)
4. 이제 결제하면 **기본 프린터로 바로** 번호표가 나옵니다.

> 확인 창이 계속 뜨면: 작업 관리자에서 `chrome.exe` 가 남아 있지 않은지 확인하고 다시 여세요.

## 3. 화면에서 고를 수 있는 것 (인쇄 설정 ▾)

| 설정 | 설명 |
|---|---|
| 결제하면 손님 번호표 바로 인쇄 | 기본 켜짐 |
| 주방 주문서도 함께 인쇄 | 번호·품목만 크게, 금액 없음 — 주방 프린터가 같은 프린터일 때 |
| 용지 폭 | 80mm / 58mm |

설정은 그 PC 에 기억됩니다.

## 4. 다시 인쇄

- 결제 완료 창의 **번호표 다시 인쇄 / 주방 주문서**
- 화면 아래 **오늘 현장판매** 목록의 **번호표 / 주방** 버튼 — 다시 찍은 번호표에는 `재출력` 표시가 붙습니다.

## 5. 카드 결제 순서

1. 상품을 담고 **카드** 를 고릅니다.
2. 카드 단말기에서 결제합니다.
3. 단말기 영수증의 **승인번호**를 입력하고 **결제 완료 · 번호표 인쇄** 를 누릅니다.
   (승인번호는 단말기 매출과 SIREN 매출을 맞춰 보는 데 씁니다.)

단말기가 목록에 없으면 업체 화면 **카드 단말기** 메뉴에서 매장별로 등록하세요 (밴사 · 단말기 ID(TID) · 이름).
고장·교체한 단말기는 **사용 중지** 하면 현장판매에서 고를 수 없어요.

## 번호표에 들어가는 것

매장 이름 · **큰 픽업 번호** · 매장/포장 · 품목과 금액 · 합계 · 결제수단(카드 승인번호) · 주류 신분증 안내 · 주문 시각 · 주문번호
