# 외부 연동 내역 (API · AI · 기타)

- 확인한 날: 2026-11-28
- 확인한 곳: 저장소 코드, 로컬 도커(`localhost:8090`, 실행 중인 `siren-app-1` 컨테이너), 카페24 개발 서버(`~/dadamda/.env`)
- 이 문서에는 **키·비밀번호 값이 없다.** 어떤 서비스를 어디에 어떤 이름의 키로 연결했는지만 적는다.

## 키를 넣는 곳

| 환경 | 키가 들어 있는 파일 | 읽히는 경로 |
|---|---|---|
| 로컬 도커 | 저장소 루트 `.env` (git 제외) | `docker-compose.yml` 이 컨테이너 환경 변수로 넘김 |
| 카페24 개발 서버 | `~/dadamda/.env` (git 제외) | 라라벨이 직접 읽음 |
| 공통 | `app/config/services.php`, `app/config/siren.php` | 위 환경 변수를 설정 이름으로 묶는 곳 |

`app/.env` 에는 연동 키가 없다 (라라벨 기본 항목만 있음).

## 2. 실제로 키가 들어가 동작하는 연동

### 페이레터 결제내역 조회
- 용도: 판매자 정산 보고서 — 기간 안 카드 승인·취소 내역을 불러와 정산액 계산
- 접속 주소: `https://pgapi.payletter.com` (`/v1.0/payments/transaction/list`)
- 키 이름
  - `PAYLETTER_URL`
  - `PAYLETTER_CLIENT_ID`, `PAYLETTER_SEARCH_KEY` — 온라인 가맹점 1
  - `PAYLETTER_CLIENT_ID_2`, `PAYLETTER_SEARCH_KEY_2` — 온라인 가맹점 2
  - `PAYLETTER_CLIENT_ID_3`, `PAYLETTER_SEARCH_KEY_3` — 매장 카드단말기 가맹점
  - `PAYLETTER_TERMINAL_STORE` — 단말기 가맹점이 속한 매장 코드 (로컬과 카페24의 값이 다름)
- **조회용 키만** 넣었다. 결제를 일으키는 키는 넣지 않았다.
- 설정: `app/config/siren.php` 의 `payletter` / 코드: `app/app/Services/PgSettlementService.php`

### KOPIS (공연예술통합전산망) 오픈API
- 용도: 전국 공연장(공연시설) 목록·상세를 가져와 공연장 등록에 사용
- 접속 주소: `https://kopis.or.kr/openApi/restful/`
- 키 이름: `KOPIS_API_KEY` (kopis.or.kr 에서 무료 발급)
- 로컬 도커에만 들어 있다. **카페24 서버에는 없어서** 거기서는 공연장 불러오기가 동작하지 않는다.
- 설정: `app/config/services.php` 의 `kopis` / 코드: `app/app/Services/KopisVenueImporter.php`

### 카이아(Kaia) 블록체인 — NFT 티켓
- 용도: 티켓을 NFT 로 발행(mint)·소각(burn)·사용 처리. 수수료는 운영사 지갑이 낸다.
- 네트워크: 테스트넷 Kairos (체인 ID 1001) — 실제 돈이 드는 메인넷이 아니다
- 접속 주소: `https://public-en-kairos.node.kaia.io` (공개 노드, 키 필요 없음) / 조회 사이트 `https://kairos.kaiascan.io`
- 설정 이름: `SIREN_NFT_CHAIN=kaia` (로컬·카페24 둘 다), 필요하면 `SIREN_KAIA_NETWORK`, `SIREN_KAIA_RPC`, `SIREN_KAIA_CHAIN_ID`, `SIREN_KAIA_CONTRACT`, `SIREN_KAIA_EXPLORER`
- 비밀 값
  - 운영사 지갑 키: `storage/app/.kaia_operator_key` 파일 (로컬 도커 볼륨·카페24 둘 다 있음, git 제외)
  - 컨트랙트 주소: DB `settings` 표의 `kaia_contract_kaia-kairos` (`artisan nft:deploy` 가 저장)
  - 팬 지갑 키: 서버가 만들어 DB 에 보관
- 설정: `app/config/siren.php` 의 `nft` / 코드: `app/app/Services/Nft/KaiaTicketChain.php`, 컨트랙트 원본 `app/blockchain/`

## 3. 코드는 준비됐지만 키가 없어 꺼져 있는 연동

### Claude API (Anthropic) — AI
- 용도 두 가지
  - 상품명 번역: `app/app/Services/Translation/ClaudeProductNameTranslator.php`
  - 좌석 배치도 그림 읽기: `app/app/Services/SeatMap/ClaudeSeatMapReader.php`
- 모델: `claude-opus-5-5` / 라이브러리: `anthropic-ai/sdk` (composer)
- 키 이름: `ANTHROPIC_API_KEY` — `docker-compose.yml` 이 받도록 돼 있지만 루트 `.env` 에도, 카페24 `.env` 에도 **넣지 않았다**
- 키가 없으면 상품명도 구글 번역 위젯이 맡고, 좌석 배치도 읽기는 쓸 수 없다.

### SNS 로그인 (네이버 · 카카오 · 구글)
- 코드: `app/app/Services/Auth/SocialAuth.php` / 설정: `app/config/services.php`
- 키 이름: `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`, `KAKAO_REST_API_KEY`·`KAKAO_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`·`GOOGLE_CLIENT_SECRET`
- 각 개발자 콘솔에 등록할 콜백 주소: `{사이트 주소}/member/oauth/{naver|kakao|google}/callback`
- 키가 없으면 그 SNS 버튼이 화면에서 숨는다. 지금은 세 곳 모두 숨은 상태.

### 비트EIS (업체 ERP) 연동
- 내보내기: 수령완료 주문 → 업체 `order_url`, 생산 입력·수정·삭제 → 업체 `production_url`
- 불러가기: EIS 가 판매내역·현재 재고를 조회해 감
- 키: 환경 변수가 아니라 **DB `vendor_integrations` 표**에 업체별로 저장 (주소, 서명 키 `secret`, EIS 코드). 요청마다 `X-Dadamda-Signature` 로 서명한다.
- 로컬 DB 에는 등록된 업체가 없다 (0곳). 카페24 DB 는 이번에 확인하지 않았다.
- 코드: `app/app/Services/OrderWebhookSender.php`, `app/app/Services/EisService.php`

### 문자(SMS)
- `SIREN_SMS_DRIVER` 기본값 `log` — 실제 발송 없이 기록만 한다 (`LogSmsSender`). 발송사 계약·연동 전.
- 카페24 `.env` 에 `SIREN_SHOW_DEV_CODES` 항목이 있다 (인증번호를 화면에 보여 주는 개발용 스위치).

### 메일
- `MAIL_MAILER=log` — 실제 발송 없이 기록만 한다. 발송사 미연동.

### 카드 결제(PG)
- `app/config/siren.php` 의 `gateways.card` 가 `MockCardGateway` (가짜 결제). 실제 PG 결제 연동 전.
- 페이레터는 **조회만** 붙어 있고, 결제 승인은 붙어 있지 않다.

## 5. 라라벨 기본 항목 (쓰지 않음)

설정 파일에 자리만 있고 키를 넣지 않았으며, 코드에서도 쓰지 않는다.

- AWS (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_BUCKET`) — 파일은 서버 디스크(`FILESYSTEM_DISK=local`)에 저장
- Postmark (`POSTMARK_API_KEY`), Resend (`RESEND_API_KEY`)
- Slack (`SLACK_BOT_USER_OAUTH_TOKEN`, `LOG_SLACK_WEBHOOK_URL`)
- Redis, Memcached — 세션·캐시는 DB 사용

| 대상 | 내용 |
